# 口语稿规范 — 书面语禁止直接进 TTS

**为什么存在**:书面稿直接喂克隆音 = 「一眼假」的第一来源——句子太长没气口、
没有语气词、节奏均匀得像机器。真人参照 = 你自己的 `voice_baseline.json`
(用 `scripts/voice_baseline.py` 从你的真实录音提取:语速带/停顿分布/句长——
真人普遍有 2s+ 的思考长停)。你在火山克隆声音时录的参考音原文就是标准答案:
短句、标点即停顿、带语气词的**说话**(如「大家好……今天呢，我们来聊聊，怎么用 AI 做内容。」),
不是书面朗读。

## 改写规则(SCRIPT.md 之前必须过这一遍)

1. **短句切分**:一句 ≤20 字为宜;书面长句拆成 2–3 个口语短句。
   呼吸组(两个长停之间)≤30 字(baseline 均值),硬上限 55 字。
2. **显式停顿标记 = 标点**(TTS 只认标点,不认括号注记):
   - `，` 短停(~0.3s):列举、切分句内节奏
   - `。` 句停(~0.45s):一个意思讲完
   - `……` 思考长停(~0.7s+):转折前、抛判断前、"想了一下"的地方——**每稿至少 2 处**,
     真人有 2s+ 的思考停顿,全片一个长停都没有 = 机器感
   - 幕尾用 `--gap-map` 加最长档(既有机制)
3. **语气词进稿**:呢 / 嘛 / 就是 / 对 / 你看 / 说真的——每 2–3 句至少一个,
   放句首或停顿后(「今天呢……」「对，就是这么快」)。别堆,一句最多一个。
4. **个人语感层**(以下是一套实战验证过的口播口径,默认启用;换成你自己的风格时,
   把你的禁用词/常用句式改进这一节):
   - 第一句话就是判断,不铺垫、不问好、不「今天给大家分享」
   - 说「我为什么这样选 / 我做了什么」,不说「大家都应该」
   - 数字具体化:「不超过 5 分钟」「两周」「4 步」,不说「很快」「大幅提升」
   - 技术词说人话:deploy→挂上去 / workflow→工作流 / optimize→调了一下
   - 禁用(出现即删):「更狠的是 / 核心就是 / 本质上 / 说白了 / 简单来说 /
     希望对你有帮助 / 首先其次最后」、递进式吹嘘、空洞大词、悬念反问
5. **读一遍测试**:改完出声读一遍(或想象读),任何一处「读着换不过气 /
   人不会这么说」就再拆。删掉一句读者什么都不少的,删。

## ASR 回读假阳性（tts_takes 报 need_rewrite 时先分辨，别急着改音频）
`tts_takes.py` 用 whisper 回读比对 CER 毙错读——但 whisper 对某些情况会**误判**（音频其实没错）。报 `need_rewrite` 时**先看 `takes/report.json` 的 asr 文本**判断是不是假阳性：
- **繁简 / 千分位逗号 / 四位数**（賺錢術問題、`3,900`、`3900`→三千九百）：已在 `tts_takes.norm` 折叠（装了 `zhconv`），一般不会再误判；若缺 zhconv 短句会误伤。
- **俚语/成语/口语约数**（「大而全」→儿权、「门清」→门倾、「快二十」→189、句首「用/AI」被吞）：whisper 真的听错/吞字，**音频没问题**。别反复重合成（stochastic 抽卡会越抽越糟）——直接把这句换成 **ASR 友好的同义词**：确数（十八/三千九百，别用「快二十」这种口语约数）、去成语（「大而全」→「功能贪多」）、去俚语（「门清」→「自己最清楚」）、句首加个字避免首词被吞。
- **专有名词/英文品牌名（无同义词可换）**：whisper 把 `Solonest` 听成 SoloNAS/Solace、把英文字母按字符计进 cps 导致**语速虚高**。
  两步处理：① 句里多加中文字稀释（英文读得快，中文字数上去 cps 就回带内）；② 若 take 除品牌名外零错、`del=0`、cps 在带内，
  就是纯 ASR 假阳性 —— 用 `--choose "5:a"` 强制定稿。`chosen_override` 在 tts_takes 里优先级最高，**exit 3 的 need_rewrite 句同样能被它定稿**
  （不只是 exit 2 的 undecided）。别为一个听不懂的品牌名反复重合成。（实战案例）
- **短句更易中招**：≤13 字的句子一两个误字就顶穿 6% 阈值；能拉长一点就拉长。
- 改完**只删该句的 `takes/NN-*.wav` 强制重合成**，别 `rm takes/*.wav` 全量重来（会把已过的好 take 重新抽卡，引入新随机失败）。

## 产出物

口语稿直接写成 SCRIPT.md(一镜一句既有格式)。改写时在稿前加一行注释
`<!-- oral-rewrite: 已过 references/oral-script.md,源稿 <路径> -->` 留痕,
gate/评审可查。书面稿原文留在项目里(`draft-source.md`)供对照。
