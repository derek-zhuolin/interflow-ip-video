### 内容分工铁律：上层抽象 ≠ 底部字幕（实战定稿红线，违反 = 返工）
底部玻璃字幕已经逐字念出**这句原话**了。上层可视化**绝不能把同一句话再写一遍**——否则「图=话」，一句话说两三遍，可视化等于没做。
- **上层 = 把这句话抽成一个「点」**：数字（`18 人`/`¥3900`/`½`）、符号关系（`技术` 被红叉划掉 / `信 →(箭头) 做` / `✕` vs `✓`）、关键词（`先收钱→再开发`，不是「先确认有人付钱再动手开发」全句）、图形（段位信号条 / 迁移弧线 / 象限）。
- **底部 = 逐字原话**（字幕的活）。上层与字幕是「图 vs 话」的互补，不是复读。
- **自检**：把该帧的上层文字和这句 voiceover 并排看——**字面重合 ≥60% = 复读，重做成抽象点**。CTA/落款帧可放结构化信息（地点/时间/署名），是唯一例外。
- 抽象点越少字越好：能用一个数字/符号说清就别写短语，能用短语就别写整句。

### 形式库复利（菜单是活的，不是封闭集）
每集**至少 1 个菜单外新形式**——从这集内容的形状里长出来（不是为新而新），出片验收后蒸馏成一行加进上面选型表（内容形状 / 形式名 / 要点），可抄原件留在该集 episode.mjs 并在要点里注明出处集名。动效语法灵感先查 `hyperframes-animation`（原子动效模式 + 场景蓝图）和 `hyperframes-creative`（audio-reactive / beat 模式），别闭门造轮子。

## 节奏与场景组（实战定稿红线：形式太跳 + 没气口 = 返工）

选型菜单是**按幕选，不是按句选**。每句一个全新形式 = 每 4s 全屏换血，观感"机关枪"。

- **先分幕**：8–12 句分 3–5 个场景组（幕），每幕一个论点（SKILL.md 步骤 2）。
- **形式预算**：全片 distinct 可视化形式 **≤5**。一幕一个形式家族，幕内演化、幕间才换。
- **骨架继承（幕内帧铁律）**：组内后续帧**复用前帧的布局坐标和已出现元素**——前帧收尾态 = 后帧初始态（继承元素静态直出，初始 opacity 就是终态值，不重播入场），只对**新增/变化**的元素做动画。视觉上是同一个镜头在推进，不是新画面。
  - kicker 幕内静态延续：初始 `opacity:1` 直出，禁重新淡入/打字；换幕才换 kicker。
  - 继承元素可降级：讲过的元素 opacity 降到 0.5–0.72 当环境，把主导让给新元素（视觉重心规则照旧）。
  - 最强的幕是**贯穿隐喻**：同一批图形元素跨帧演化（例：席位点排 → 同批点落进漏斗 → 剩下的点配巨字），观众看到"同一群人"被讲了三句。
- **转场**：幕内 `transition_in: cut`（骨架继承下硬切无感），幕间 `crossfade`。整片 crossfade 到底 = 节奏太跳。
- **气口**：TTS 默认 auto 模式，按句尾标点分档 + 抖动（？！0.5–0.65s / ，0.3–0.4s / 。0.4–0.55s / 幕尾 0.65–0.85s）——固定等长的气口听着像节拍器，跟没气口一样不自然。帧动效要给气口留**静帧呼吸拍**——元素在语音结束前发育完，气口期间只留呼吸辉光/浮动等低频循环，禁新元素进场；口型包络自动闭嘴。
- **入场密度降档**：幕内帧动画对象 ≤3 个（新增元素 + 强调），别把整帧重新 stagger 一遍。

## 变奏轴（防"每集长一个样"——同一形式每次换组合）
四条正交轴，**相邻幕禁止重复同一组合**；每集开工先列一张「幕 × 形式 × 入场 × 强调 × 纹理」表再写 config，撞车一眼可见：
- **入场性格**：y 上浮（默认）/ x 侧滑 / scale 沉入（0.92→1, power3.out）/ clip-path 揭示（gsap 补间 `clipPath: inset()` 从一侧扫开，seek-safe）/ 模糊聚焦（filter blur 8→0 + opacity）
- **舞台呼吸**：主体容器全时长缓慢 scale 1.0→1.03 或 y 0→−14 匀速漂移（Ken Burns 感，`ease:"none"`，叠在入场动画外层容器上不冲突）——静帧也有生命
- **强调语法**（那一处红的出现方式，每幕换）：呼吸辉光 / 红下划线 draw / 手绘圈 / 徽章弹入 / 印章砸落 / 端点脉冲
- **背景纹理**（幕间可换，透明度/克制度规范不变）：32px 方格（默认）/ 品牌波浪线一角 / 点阵栅格（radial-gradient 圆点）/ 细扫描线（3px 横纹 2% 白）

## 设计 DNA v2（字阶 / 间距 / 图内文字纪律——guizang 秩序系统，2026-07-20 起 gate 硬校验）

「无序」的根源是每帧现挑数值。v2 把字号、间距、图内文字全部收进固定标尺——**帧内不再发明数值，只从档位里选**。

### 字阶（8 档，帧内 font-size 只取这些值；SVG viewBox 内部是另一坐标空间，不受限）
| token | px | 用途 | 生成器类 |
|---|---|---|---|
| note | 26 | 小注/轴标/HUD 表头/mono 数据行 | `.t-note` |
| label | 34 | kicker（`.kick` 已锁）/CN 图内标签/EN tracked 标签 | `.t-label` |
| body | 44 | 胶囊内文/说明行（少用——句子本来不进图） | `.t-body` |
| h3 | 64 | 徽章大字/次级数字/小标题 | `.t-h3` |
| h2 | 92 | 次主导/说明词 | `.t-h2` |
| h1 | 130 | Anton stat 数字/中巨字 | `.t-h1` |
| giant | 180 | CN 巨字主导 | `.t-giant` |
| mega | 260 | 1–2 字超巨/收尾落版 | `.t-mega` |

- **每帧 distinct 字号 ≤4 档**（层级多 = 没层级；guizang：图内文字层级要少）。gate 查：字号 ∉ 字阶 或 >4 档 = FAIL。
- 文字要「再大一点/小一点」→ 跳到相邻档，不发明中间值；要塞下更多字 → 删字，不缩字号。
- 视觉重心规则照旧（主导 ≥3× 次级）：giant/mega 配 label/note 天然满足。

### 间距（8px 节拍，净距只取档位）
- 净距档位：**24 / 40 / 64 / 96**（元素间 ≥40 与标签-图形 ≥24 的既有红线不变，加档位化：别再出现 33px、47px 这种目测值）。
- **左右安全边距**：内容外接盒 x ∈ [60, 1020]，标签不贴边（guizang：labels away from edges）。
- 构图带照旧：kicker ~y260 / 主体 y280–1360 / 呼吸带 y1360–1500 / 对话排 y1500–1750。

### 图内文字纪律（guizang 标签 DNA）
- **图内标签 2–5 字，6 字封顶**；超了 = 该文字不属于图内，挪出图形区或删。
- **具体名词，不抽象名词**：`用户提示`/`AI 执行`/`结果检查`，不是 `输入阶段`/`执行阶段`/`验证阶段`。
- **每帧图内标签 ≤5 个**（不含 kicker/巨字主导）；要讲的点多 = 拆帧，不是堆标签。
- **一帧一隐喻**：循环/管线/中心辐射/对比分屏/层叠——一帧只用一种图式，禁混搭（cycle + 仪表盘 + 路线图挤一帧 = 返工）。
- 句子不进图（内容分工铁律照旧）：上层是「点」，字幕是「话」。

## 质感规则（每帧强制，生成器 COMMON/BG 已内置）
- 背景禁纯色平面：radial 暗渐变底（中心微光晕）+ **32px 细网格**（3.5% 白，入场 0.6s 淡入）+ 四角 vignette
- SVG stroke **≥ 2.5px**，`stroke-linecap: round`
- **禁细浅图标**（定稿偏好）：图标类线稿（椅子/物件等具象小图标）stroke **9–12px** + `stroke-linejoin:round` + opacity ≥0.85，端点圆润转角带 Q 弧；结构性线稿（窗口/卡片/手机外框）stroke **4px**。2.5px 细线只留给网格/基线/刻度这类辅助线
- 线稿容器统一微辉光 `drop-shadow(0 0 7px rgba(255,255,255,0.20))`；关键路径 `.glow-w`（10px 35%）
- 每帧至少三层：背景纹理层 / 主体层 / 强调层
- **圆润化（Apple 式圆角，拒硬直角）**：窗口/终端 rect `rx≥36`、卡片 `rx≥44`、手机 `rx≥58`；实心多边形（播放三角等）用同色粗描边 + `stroke-linejoin:round` 圆角化；小色块（光标等）加 `border-radius`；直线端点一律 round cap
- **构图带**：kicker ~y260–300 起，主体内容带 y280–1360；**底部对话排 y1500–1750** = IP 小人（左下 40–236）+ 字幕对话气泡（264–1044，小人右侧），内容禁入；y1360–1500 留空当呼吸带——内容坠到对话排上 = 返工
- **间距红线（贴脸 = 返工）**：垂直堆叠元素按**外接盒**留 ≥40px 净距；图标容器实高按 svg viewBox 算（画到 viewBox 底 = 容器底），标签/文字禁与图形外接盒相交。建帧时逐帧列一遍各元素的 top/bottom 数一数
- **kicker 规格**：EN kicker 统一 34px（生成器 COMMON 的 `.kick` 类），禁 24px 小字——1080 宽画布上 24px 读不清
- **视觉重心（每帧一个主导元素）**：每帧恰好一个主导元素（巨字/图表/图形），显著大于其他——标题/巨字字号 ≥3× 次级文字字号。**禁止等大平铺**：清单/时间轴/多项帧也要有主次——当前讲到的项放大或高亮，其余收小/降透明度，禁止所有项一样大小铺在那里

## 圆形节点标签规范（圈盖不住字 = 返工）
时间轴/迁移/流程图里的圆形节点配文字标签时：
- **圆内标签**：文字总宽（字数×字号）必须 ≤ 1.3×r，即 **r ≥ 0.65×字数×字号**（例：2 字 30px → r≥40）
- **圆内最多 2 字**；≥3 字（如「你的需求」）禁塞圆内 → 放圆外下方/旁边（与圆外接盒净距 ≥24px），或干脆改用**圆角胶囊 rect**（rx=高/2）装文字
- **禁标签与圆边相交/半压圆边**——标签外接盒要么完全在圆内（按上面 r 公式），要么完全在圆外

## 手绘圈注（红圈强调）规范
巨字/关键词的红圈强调**禁用标准 `<ellipse>`**——太规整像几何题，且 draw-on 起收笔是生硬接缝。标准做法：
- **手绘 path**：四段 cubic 绕一圈，**收笔越过起笔重叠一段**（真实下笔感，也吃掉 draw-on 接缝）。模板（viewBox 480x440，中心 240,225）：
  `M 300 55 C 180 22, 70 80, 48 180 C 28 275, 95 375, 215 395 C 340 415, 440 340, 442 230 C 444 120, 360 50, 250 46 C 225 45, 202 50, 185 58`
- **比例**：宽圆不蛋形——rx:ry ≈ 1.1:1；内容横向 pad ≥40% 字宽、纵向 pad 10–15%（巨字 330px 配 480x440 的圈）
- **姿态**：整体 `rotate(-6°)`（transform 显式支点）；stroke **7–8px** round（跟粗线稿语言一致，5px 太细）
- **动效**：draw-on 0.9s `power2.inOut`，配 addGlowPulse 红呼吸

## Hero 图勘测 HUD（单图讲解）规范
适用：讲一件实物/产品/作品/截图——有一张真实图片当主角。灵感原型 = HyperFrames "field survey" demo（HUD 面板逐字勘测 + 锚线 + macro 取景框）。生成器示例见 generator-base 示例 C。
- **素材**：hero 图放项目 `public/`（用户供图，或 fal-generate 生成后 remove-background 可选）。**引用一律项目根相对路径 `public/hero.png`，禁 `../` 父级穿越**（子合成克隆进 host 页后按项目根解析；`../../public/` 是 lint error，Studio 直接 404）。**裂图在暗底上不易察觉**，snapshot 必须确认图真实加载。
- **竖屏三件套布局**（原横屏三栏改竖排）：hero 图居中 y≈330–950（宽 ≤860，`border-radius:44px` 裁切 + 1.5px 白 12–14% 描边）；HUD 面板左下 y≈1030–1360（宽 ~600）；macro 取景框与 HUD 并排右侧（~320 宽）。全部 y≤1360，件间净距 ≥40px。
- **HUD 面板**：暗玻璃卡 `rgba(255,255,255,0.055)` + 1.5px 白 12% 描边，rx≥36；表头 Archivo tracked 24–26px muted；数据行 **IBM Plex Mono**（FONT 已内置）30px 白。
- **typewriter 必须 seek-safe**：onUpdate 里 `n = clamp(floor((t - t0) × 25), 0, len)` 截 `data-text` 到 textContent；光标 = 白色小圆角块，位置用 `offsetLeft + offsetWidth` 跟随当前行（布局测量是显示文本的纯函数，seek-safe），闪烁 = `(t % 1.0) < 0.5`。禁 CSS steps()/transition/TextPlugin。
- **锚线（leader line）**：虚线 `stroke-dasharray:3 14`、3.5px round——**禁挂 data-draw**（DRAWSETUP 会把 dasharray 改成总长，虚线直接消失）；出现用淡入，换锚点用 `attr:{x2,y2}` 端点补间。锚点 = **该帧唯一红**：8–10px 实心红圆（inline style）+ addGlowPulse 呼吸。
- **macro 取景框**：同一张图第二次引用，`background-size` 放大 2.5–3.5×、`background-position` 负偏移对准锚点；切换取景 = tl 补间 backgroundPosition（与锚点移动同拍 power2.inOut）；框内四角加 L 形白角标（取景器语言），rx≥36。
- **节拍**（words[] 锚）：讲到某部位 → 锚红点移位 + 锚线跟随 + HUD 新行 typewriter + macro 重新取景，四件事同拍；收尾可打白色「COMPLETE」类徽章（红仍只在锚点）。

## 玻璃 stat 卡排（并列数据/事实）规范
适用：一句话里 2–3 个并列数字/事实（"X 万下载、Y 星、Z 个技能"）。生成器示例见 generator-base 示例 D。
- **卡**：暗玻璃 `rgba(255,255,255,0.05)` + 1.5px 白 10% 描边，rx≥44；卡内三行 = Archivo tracked 小标签(26px muted) / 巨数(Anton 或 Noto 900，≥120px 白) / muted 小注(26px)。数字**只用文稿里有的**（禁编造规范照旧）。
- **竖排堆叠**（1080 宽横排三张会挤瘦），每张 ~300 高、张间 ≥40px，整排落主体带 y340–1360。
- **逐张 stagger 进场**：进场时刻逐张锚 words[]——说到哪个数字哪张进（`fadeUp` 标准入场，y+40→0 + opacity ~0.5s），禁同帧齐出。
- **主次**：当前讲到的卡 opacity 1 + scale 1.02，讲过的降到 0.72——收尾三张可齐亮定格。禁三张等大同亮平铺（视觉重心规则照旧）。
- **红一处**：只给最关键一张卡数字旁的小图标/角点，其余全白灰。

## 媒体帧与贴纸（素材库形式：media-full / media-pip / media-bg / avatar-frame + 贴纸 overlay）

素材从哪来、怎么进项目、怎么算「命中」→ `references/media-library.md`（manifest/合并/prep/回退）。
这里只管排版与红线。**前提铁律：media-* 三形式只在 STORYBOARD media 字段语义命中时可选**——
无命中回退纸雕/图表帧，**禁止硬配无关图**（这条 gate 查不了像素，靠选型自律 + 快照复核）。

- **media-full（素材即主体）**：盒默认 `0,0,1080×1360` 通栏（内容带红线 y≤1360 照旧，底部对话排保留=品牌恒常）；
  底部 30% 自动渐隐（`.mfade`）融进暗底。图片：生成器自动 Ken Burns（scale 1.02→1.07 匀速，seek-safe）。
  kicker 可压素材上沿排。红一处照旧（角标/红贴纸都算那一处）。
- **media-pip（画中画）**：玻璃窗默认 `110,430,860×560 rx44`（config `media.box` 可覆写），文字主体照常；
  周边文字与窗**外接盒净距 ≥40px**。视频比帧短/注入前，玻璃垫底窗接住尾巴。
- **media-bg（暗化垫底）**：全幅素材 + `rgba(7,7,8,0.62)` 暗化盖层，文字主体照常排 y280–1360，
  视觉重心规则照旧（一个主导元素）。视频版生成器自动把帧背景换半透明垫（真视频在 root under 层）。
- **视频 B-roll 通用**：素材必须先过 `prep_media.sh`（物理静音 + 裁至 min(beat,4s) + 烘焙旋转）；
  帧内**永远不写 `<video>`**（子合成媒体 = assemble HARD FAIL），管线末尾 `inject_broll.mjs` 注入
  index.html root。视频 beat 控制在 ≤4s 语音，建议 `transition_in: cut` 进（视频起点是硬切）。
- **avatar-frame（数字人段）**：`avatar:{provider:"local-rig"}`——纸雕小人放大居中
  （`240,520,600×766`），口型/浮动/眨眼/姿势走同一 animChar + RMS 包络，角落常驻位自动让位
  （禁双人）。配 kicker/侧注排小人上方或两侧（与小人外接盒净距 ≥40px）。
  provider=heygen 未接入：生成器打 warn 自动降级 local-rig，**永不阻塞出片**；将来接入也必须
  失败/超时自动降级 + 复用同一音色源。
- **贴纸 overlay（不是形式，是槽位）**：任何帧可挂 **≤2 个**，`stickers:[{id,path,x,y,w,h,at}]`，
  GSAP `back.out` 弹入（scale 0.3→1 + rotation −14→0），`at` 锚 words[] 语义节点。
  外接盒**禁入字幕安全区（y≥1500）**、禁出画布；**红色贴纸挂帧 = 该帧唯一红**（svg 里的红不进
  markup 计数，gate 数不到——自律 + 快照）。贴纸是点缀，不改变纯文字帧判定（kind 不因贴纸升级）。

**媒体红线（已进 gate，查 slots.json 声明层）**：连续纯文字帧 ≤2；非纯文字帧占比 ≥40%；
引用素材存在且可解码；视频 B-roll 无音轨且 ≤4s；贴纸 ≤2/帧且不入字幕安全区；全片仅一个音色。
纯文字帧生成器按 body 有无图形自判，巨字+红下划线这类"排版帧"会被算 viz——**确实通篇只有字的帧
用 `kind:"text"` 如实标注**，别靠误判蒙混占比。

## 动效系统（Emil Kowalski 决策树的视频语境版，2026-07-20 起 tokens 进生成器、红线进 gate）

动了但「不合理」的根源：每个补间现挑 ease 和时长。v2 收进 tokens——**写动效先过决策树，值从 tokens 取**。

### 先问为什么动（purpose；答不上来就别动）
视频语境三种合法目的：**节拍对位**（reveal 锚 words[] 词级时间戳）、**空间叙事**（元素从它的语义来源方向进场）、**状态强调**（那一处红的出现）。"看起来酷"不是目的；装饰性乱动 = 返工。

### easing 决策树（GSAP 映射；生成器已注入 `EASE` tokens）
- 入场/出现 → **`EASE.enter` = power4.out**（= Emil 强 ease-out 曲线 cubic-bezier(0.23,1,0.32,1)；起步快收尾缓，观感最跟手）
- 在场移动/变形/换锚点 → **`EASE.move` = power3.inOut**（= 他的强 in-out (0.77,0,0.175,1)）
- 线条 draw-on → **`EASE.draw` = power2.out**（手绘圈注/下划线这类"起收笔"特例可 power2.inOut）
- 高光弹入（印章/贴纸/徽章）→ **`EASE.pop` = back.out(1.7)**，overshoot 要克制
- 匀速循环（Ken Burns/飞行点相位/呼吸）→ `"none"`，onUpdate 确定性函数
- **永不 `*.in`**（power2.in/expo.in…全禁，gate 硬查）：ease-in 起步慢，慢在观众正盯着的那一刻。

### 时长档（`DUR` tokens；视频是"讲解档"可比 UI 慢，但纪律一致）
| token | s | 用途 |
|---|---|---|
| pop | 0.35 | 小件：红点/徽章/角标/图标；kicker 淡入也用这档 |
| enter | 0.5 | 标准入场：文字行/标签/中元素 |
| panel | 0.65 | 大件：卡片/面板/hero 图 |
| draw | 1.0 | 线条 draw-on（带宽 0.8–1.2） |
| breathe | 2.0 | 呼吸辉光/低频循环周期 |

单个入场补间 **≤0.7s**、draw ≤1.2s——再长就是拖（Emil：慢的入场"感觉"更慢）。

### 物理感（永不从无而来）
- **禁 `scale(0)` 入场**（gate 硬查）：面板/卡片从 **0.92–0.96** 起，小件 ≥0.6；贴纸/印章的戏剧弹入 ≥0.3（一集少量高光才允许）。
- **origin-aware（有来处）**：强调件从它的锚点方向长出来——徽章 transformOrigin 朝线端点、标签从所属节点方向淡入。HTML 元素才用 transformOrigin；**SVG 组入场用平移 fadeUp 或 onUpdate 显式支点**（pitfalls：GSAP transform-origin 在 SVG 细线/组上会漂）。
- 入场位移：标准 `RISE=40`px，巨字 60，小件 16–24——同帧别混三种位移量。

### 编排（orchestration）
- **每拍一次编排**：同一词锚触发的多个动作是"一次协调运动"——主动作起点 = 词时间戳，从动作错峰 ≤0.12s；不是各排各的时刻表。
- **stagger 60–90ms**（`STAGGER=0.08`；Emil：UI 30–80ms，视频画布大取上带）；>120ms 显拖沓。禁同帧齐出。
- **高频恒常件降级**（frequency 原则）：每帧都出现的 kicker/字幕/小人入位，动效最短最淡（kicker 0.35s 淡入、幕内直出）；一集一次的高光（印章/爆发/CTA）才允许 overshoot/戏剧化。
- **不对称节奏**：铺垫可慢（draw 1.0s），强调要快（红点 0.35s）——"慢铺垫、快强调"。

### 帧内节奏（既有规则不变）
- 每帧全时长发育：入场 ~20% → 强调 ~60% → 收束 ~20%，禁"出现后死站着"
- 强调元素带循环二级动画：`addGlowPulse`（DUR.breathe 呼吸辉光）；弧线加飞行点
- 触发时刻禁手写秒数：一律 `wordT/pauseT` 从 beat_map 取（SKILL 步骤 5 铁律）
- seek-safe 铁律：无 repeat/yoyo/random/Date；一切"循环感"= t 的确定性函数
- 生成器 helpers：`fadeUp(sel,at,{y,dur,ease})` / `popIn(sel,at,{from,origin})` / `fadeIn(sel,at,{to})`——标准入场一律用它们（tokens 自动带对），raw gsap 留给复杂编排。
